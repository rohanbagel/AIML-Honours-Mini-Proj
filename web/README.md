# Diabetes Risk Prediction Dashboard — Web Application

This directory contains the single-page frontend application for the **BE AI&DS Healthcare AI/ML Mini Project: Diabetes Risk Prediction Dashboard**.

Built with **React 18**, **Vite**, and **Recharts**. Operates completely client-side without any backend server.

---

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 3. Build for Production
```bash
npm run build
```
Creates an optimized static production bundle in `dist/`.

### 4. Preview Production Build
```bash
npm run preview
```

## Architecture & Data Flow

- **Zero-Backend Architecture**: All metrics, statistical distributions, confusion matrices, and model weights are imported directly from `src/results.json` (generated by `notebook/diabetes_analysis.ipynb`).
- **Client-Side Predictor (`src/predict.js`)**: Executes standardized Logistic Regression inference in the browser ($z_i = \frac{x_i - \mu_i}{\sigma_i}$, $\text{logit} = \beta_0 + \sum \beta_i z_i$, $P = \frac{1}{1 + e^{-\text{logit}}}$). Replaces missing/zero physiological measurements with training-set medians.
- **Inference Parity**: Automatically validated on mount against scikit-learn's `predict_proba` on 5 held-out test cases ($< 0.001$ maximum error).
- **Ask the Data (`src/knowledge.js` & `src/gemini.js`)**: Natural-language Q&A assistant powered by Google Gemini (`gemini-3.6-flash`). Uses a compact plain-text knowledge base synthesized at runtime from `results.json`. The user's API key is stored strictly in `sessionStorage` and React state for that browser tab.
